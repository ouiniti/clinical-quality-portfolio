# Clinical Quality Portfolio

A modern web application for Hospital Quality Improvement (HA). Built with React, Vite, Tailwind CSS, and Supabase.

## Features
- **Dashboard**: Summary stats for reviews, success rates, and active projects.
- **Submission Form**: Clean interface to input quality records (Clinical Population, Review Type, Indicators).
- **Portfolio**: Searchable and filterable grid of collected works.
- **Analytics**: Visualization of indicator trends and project distribution.

## Tech Stack
- **Frontend**: React (Vite)
- **Styling**: Tailwind CSS, Lucide React (Icons)
- **Database**: Supabase
- **Charts**: Recharts

## Setup Instructions

### 1. Database Setup (Supabase)
1.  Create a new project on [Supabase.com](https://supabase.com/).
2.  Go to the **SQL Editor** and run the following script to create the main table:

```sql
create type clinical_population as enum ('DM', 'HT', 'Elderly', 'Pediatric', 'Stroke', 'Other');
create type review_type as enum ('Chart Review', 'Med Error', 'RCA', 'Audit', 'Innovation');
create type improvement_dimension as enum ('Prevention', 'Promotion', 'Cure', 'Rehabilitation');

create table quality_records (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  title text not null,
  clinical_population clinical_population not null,
  review_type review_type not null,
  target_indicator text,
  actual_indicator text,
  improvement_dimension improvement_dimension not null,
  description text
);
```

### 2. Connect the App
1.  Copy `.env.example` to `.env` (create it if missing).
2.  Add your Supabase details to `.env`:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. Run Locally
```bash
npm install
npm run dev
```

## Deployment

### Deploy to Vercel
1.  Push this code to a GitHub repository.
2.  Go to [Vercel](https://vercel.com/) and "Add New Project".
3.  Import your GitHub repository.
4.  In the "Environment Variables" section, add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` with your Supabase credentials.
5.  Click **Deploy**.

### Deploy to GitHub Pages
1.  Update `vite.config.js` to set the `base` path if needed (e.g., `base: '/repo-name/'`).
2.  Run `npm run build`.
3.  Deploy the `dist` folder using `gh-pages` or GitHub Actions.
